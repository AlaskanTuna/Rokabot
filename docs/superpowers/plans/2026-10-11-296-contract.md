## Adapter Rules

- Every adapter is an ADK `BaseLlm` and accepts the same `LlmRequest` the agent builds.
- **Structured output:** when `llmRequest.config.responseJsonSchema` is set, the adapter returns the JSON object as the text of the first response part. Gemini passes it through; Anthropic forces one output tool; Chat Completions uses `json_schema` (strict) or `json_object` per profile. 1A implements Gemini and Anthropic; 2 implements Chat Completions.
- **Request shaping** (`requestShape.ts`, 1A): drops `temperature`/`topP` when the profile disallows them, drops `safetySettings` for non-Gemini, clamps `maxOutputTokens` to the resolved value.
- **Tool calls** keep provider call ids end to end; results are matched by id, never by name.
- **Thinking** (D10): kept only for the current turn's tool loop; never written to session history.
- **Errors:** throw `ProviderError` with the right kind; SDK automatic retries are off.

## Contract Amendments (2026-10-11, After the Five Plans)

These resolve the "Contract Issues" each plan raised. They override any plan text that disagrees. A builder reads this section before its plan.

### Merge Order

1A → 1C → 1B → 2 → 1D. Each branches from `main` after the previous merge (or merges `main` in before its PR). 1D goes last because it changes budget internals that every adapter already calls.

### Seams

1. **Workload:** adapters read it with `workloadOf(llmRequest)` from `usage.ts`, which reads `llmRequest.config.labels[WORKLOAD_LABEL]` (`WORKLOAD_LABEL = 'rokabot_workload'`) and defaults to `'reply'`. `generateObject` sets the label. No AsyncLocalStorage.
2. **Budget Entry Point:** 1A's `budget.ts` also exports `startCall(input: { provider; model; workload; estTokens; signal?: AbortSignal }): Promise<CallReservation>` (stub: `grantOrThrow(input.provider, reserveCall(input))`) and `markBillingExhausted(provider: ProviderId): void` (stub: no-op). Every adapter calls `await startCall(...)` before each provider request, never `reserveCall` directly. It calls `reservation.release(usage)` after the call with the same `CallUsage` given to `recordUsage`, or `release()` with nothing when the call failed before usage came back. 1D replaces the internals of `budget.ts` only and does not edit adapters.
3. **Denials:** `monthly` → `billing_exhausted`; `rpm` / `tpm` → `quota_exhausted` with `retryAfterMs: 60_000`; `rpd` → `quota_exhausted` with `retryAfterMs` until the next UTC midnight. In phase 1 the sticky window stays `stickyMs`; it does not read `retryAfterMs`.
4. **Billing Hook:** an adapter that classifies a provider's own billing error as `billing_exhausted` (Anthropic credit exhausted, OpenAI `insufficient_quota`) calls `markBillingExhausted(provider)` before throwing.
5. **Request Shaping:** the adapter calls `shapeRequest`, not the router. It clamps output to `ResolvedModel.maxOutputTokens`. 1B builds its background adapters from a copy of the `ResolvedModel` whose `maxOutputTokens` is the request's own value, capped by `profile.maxOutputTokens`.
6. **ProviderError Fields:** readonly `provider`, `kind`, `status?`, `retryAfterMs?`, `cause?`, and `name === 'ProviderError'`.
7. **Tool-Call Pairing:** by provider call id. ADK strips its own `adk-` ids, so an id-less result pairs with the earliest unanswered id-less call of the same name in the preceding model turn.
8. **Pinning:** `RoutedLlm` pins a turn to one side only when that side's profile has `thinking.replayWithinTurn` (option `pinTurns`), so the legacy route keeps hedging tool round-trips. `ModelRoute.pinned` is unchanged.

### Types

9. **CallUsage Buckets Are Disjoint:** `inputTokens` excludes cache reads and writes. `outputTokens` excludes `reasoningTokens` when the provider reports reasoning separately. When it does not (Anthropic), `reasoningTokens` is omitted and `outputTokens` is the billed output.
10. **ModelProfile.price** gains `cacheWrite?: number` (USD per 1M tokens). Haiku 5.5 uses 1.25 × its input price.
11. **generateObject** returns `{ value, provider, model, usage: CallUsage }`.
12. **config.llm** gains `modelscopeDailyMagicubes: number` (1D adds it).
13. **config.embeddings** is a superset: it also has `dim`, `fingerprint`, `backfillBatchSize` and `backfillGapMs`; `apiKey` is `string | undefined`. A `local` model id has the form `<repo>@<rev8>-<dtype>`.

### Behaviour

14. **Embeddings Default:** with no `embeddings:` block, the provider is `gemini` (today's model, 768 dimensions) when `GEMINI_API_KEY` is set, else `local`. The Gemini 768-dimension space reads `unknown`-provenance vectors, and backfill runs only after a switch away from Gemini. Embeddings call neither `recordUsage` nor `startCall` in phase 1.
15. **GEMINI_API_KEY (1B):** required only when the main or fallback model is Gemini, the resolved embeddings provider is `gemini`, or the media watcher is on. 1B lands after 1C, so it uses the resolved `config.embeddings.provider`.
16. **Legacy Judgments:** with no TypeSafe key, the legacy config keeps today's behaviour; 1B adds main-model judgments only when an `llm:` block exists.
17. **Chat Completions:** a malformed tool-argument reply throws `malformed_tool_args` (also on the legacy fallback, so it cannot win a hedge race). OpenAI `insufficient_quota` maps to `billing_exhausted`.
18. **context_length** switches once like the other new kinds. History trimming is a follow-up, not phase 1.
19. **Ownership:** `src/agent/llm/budget.ts` is created by 1A as a stub and owned by 1D.

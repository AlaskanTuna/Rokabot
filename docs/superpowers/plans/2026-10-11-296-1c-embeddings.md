# Embeddings (#296 Plan 1C) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Route every memory embedding through one `EmbeddingClient` (local sidecar, Gemini or OpenAI), record each stored vector's provenance, recall only vectors from the configured embedding space, and backfill vectors after a provider switch, while a config without an `embeddings:` block keeps today's Gemini behaviour exactly.

**Architecture:** `src/agent/memory/embeddings/` holds the seam (`client.ts`), one adapter per provider and a pure `fingerprint.ts`; `embedEpisodeText` stays as a thin facade, so every caller and test mock keeps its import path. The three vector tables gain `embedding_model_id`, `embedding_dim` and `embedding_fingerprint`; the stores decode only vectors in the configured space (vectors stored before this plan are `unknown`, and only the Gemini space reads them), so recall code barely changes and the existing maintenance loop becomes a paced, bounded, resumable backfill. The `local` provider is a Debian Node 24 sidecar (`sidecar/embeddings/`) running Transformers.js with a baked, checksummed `Xenova/multilingual-e5-small` q8 model under the compose profile `local-embeddings`.

**Tech Stack:** TypeScript on Node 24, vitest, better-sqlite3, `@google/genai` (Gemini embeddings), `fetch` (sidecar and OpenAI), `@huggingface/transformers` 4.3.0 with `onnxruntime-node` 1.30.0 (sidecar only), Docker Compose.

## Design Decisions

1. **Fingerprint format.** `<provider>:<model>:<dim>:<recipe>`: `gemini:gemini-embedding-2:768:gemini-task-prefix`, `local:Xenova/multilingual-e5-small@761b726d-q8:384:e5-prefix-mean-l2`, `openai:text-embedding-3-small:1536:raw`. The recipe names the provider's preprocessing. The local model id carries the Hugging Face revision and the quantisation, so a rebuilt sidecar is a new space.
2. **Active space.** `config.embeddings.{provider, dim, fingerprint}` is fixed at startup. A store decodes a vector only when its recorded dimension matches, its bytes equal `dim × 4`, its fingerprint matches (or is `unknown` while the provider is `gemini`), its values are finite and its norm is nonzero. Anything else reads as "no vector". Queries come from the configured client, so they are always in the active space.
3. **Why `unknown` stays readable by Gemini.** Every vector stored before this plan came from the one Gemini 768-dimension recipe (#223: `gemini-embedding-2`, not env-overridable). If those vectors were unreadable, semantic recall on the Pi would go blank until a full Gemini re-embed. That would change the legacy config's behaviour (see Contract Issues).
4. **Thresholds.** `memory.*MinSimilarity` stay the Gemini calibration. `embeddings.minSimilarity['<fingerprint>']` overrides them for that fingerprint. Config resolves the active values into `config.memory.*MinSimilarity`, so recall code does not change.
5. **No usage or budget calls for embeddings.** The runbook states that embedding requests never debit the generation rate limiter. 1D's per-call reservations would make legacy embedding calls compete with replies, so paid-embedding accounting waits for Phase 3 (see Contract Issues).
6. **Facade.** `embedEpisodeText({ text, role, signal })` keeps its signature and now returns `EmbeddingResult`. Writers pass the result straight to the stores. Query callers take `.values`.

```ts
export type EmbeddingProvider = 'local' | 'gemini' | 'openai'

// The sidecar names its model by repository, revision and quantisation, so a rebuilt image is a new embedding space.
export const LOCAL_EMBEDDING_MODEL = 'Xenova/multilingual-e5-small@761b726d-q8'

export const DEFAULT_EMBEDDING_MODELS: Readonly<Record<EmbeddingProvider, string>> = {
  local: LOCAL_EMBEDDING_MODEL,
  gemini: 'gemini-embedding-2',
  openai: 'text-embedding-3-small'
}

// How each provider prepares text. A vector made under another recipe is not comparable, even from the same model.
const RECIPES: Readonly<Record<EmbeddingProvider, string>> = {
  gemini: 'gemini-task-prefix',
  openai: 'raw',
  local: 'e5-prefix-mean-l2'
}

export function embeddingDimensions(provider: EmbeddingProvider, model: string): number | undefined {
  // Every Gemini request asks for outputDimensionality 768, whatever the model (#223).
  if (provider === 'gemini') return 768
  if (provider === 'openai') return model === 'text-embedding-3-small' ? 1536 : undefined
  return model === LOCAL_EMBEDDING_MODEL ? 384 : undefined
}

export function embeddingFingerprint(provider: EmbeddingProvider, model: string, dim: number): string {
  return `${provider}:${model}:${dim}:${RECIPES[provider]}`
}

export function isEmbeddingVector(value: unknown, dim: number): value is number[] {
  return (
    Array.isArray(value) &&
    value.length === dim &&
    value.every((item) => typeof item === 'number' && Number.isFinite(item))
  )
}
```

```ts
function embeddingProvider(): EmbeddingProvider {
  const envValue = envString('EMBEDDINGS_PROVIDER')
  // A config.yml from before the embeddings block keeps today's Gemini vectors; a block that omits provider gets local.
  const value = envValue ?? yaml.embeddings?.provider ?? (yaml.embeddings ? 'local' : 'gemini')
  if (value === 'local' || value === 'gemini' || value === 'openai') return value
  const source = envValue ? 'Environment variable EMBEDDINGS_PROVIDER' : 'Config value embeddings.provider'
  throw new Error(`${source} must be local, gemini or openai, got: ${String(value)}`)
}

const EMBEDDING_KEYS: Readonly<Record<EmbeddingProvider, string | undefined>> = {
  gemini: 'GEMINI_API_KEY',
  openai: 'OPENAI_API_KEY',
  local: undefined
}

function resolveEmbeddings() {
  const provider = embeddingProvider()
  // memory.embeddingModel is deprecated and only ever named a Gemini model.
  const legacyModel = provider === 'gemini' ? yaml.memory?.embeddingModel : undefined
  const model = yaml.embeddings?.model ?? legacyModel ?? DEFAULT_EMBEDDING_MODELS[provider]
  const dim = embeddingDimensions(provider, model)
  if (dim === undefined) {
    throw new Error(`Config value embeddings.model is not a tested ${provider} embedding model, got: ${model}`)
  }
  const apiKeyName = EMBEDDING_KEYS[provider]
  return {
    provider,
    model,
    dim,
    fingerprint: embeddingFingerprint(provider, model, dim),
    timeoutMs: yaml.embeddings?.timeoutMs ?? yaml.memory?.embeddingTimeoutMs ?? 1500,
    sidecarUrl: yaml.embeddings?.sidecarUrl ?? 'http://embeddings:8080',
    apiKey: apiKeyName ? requiredEnv(apiKeyName) : undefined,
    backfillBatchSize: yaml.embeddings?.backfillBatchSize ?? 3600,
    backfillGapMs: yaml.embeddings?.backfillGapMs ?? 1000
  }
}

const embeddings = resolveEmbeddings()
const similarityFloors = yaml.embeddings?.minSimilarity?.[embeddings.fingerprint]
```

```ts
export interface FetchCall {
  url: string
  init: RequestInit
}

export function fakeFetch(respond: (call: FetchCall) => Response | Promise<Response>) {
  const calls: FetchCall[] = []
  const fetchImpl = (async (input: string | URL | Request, init?: RequestInit) => {
    const call = { url: String(input), init: init ?? {} }
    calls.push(call)
    return respond(call)
  }) as unknown as typeof fetch
  return { fetchImpl, calls }
}

export function json(body: unknown, status = 200): Response {
  return new Response(JSON.stringify(body), { status, headers: { 'content-type': 'application/json' } })
}

/** A fetch that settles only when its signal aborts, rejecting with the abort reason. */
export function hangingFetch() {
  return fakeFetch(
    ({ init }) =>
      new Promise<Response>((_resolve, reject) => {
        init.signal?.addEventListener('abort', () => reject(init.signal?.reason), { once: true })
      })
  )
}
```

```ts
import { logger } from '../../../utils/logger.js'
import type { EmbeddingClient, EmbeddingSettings } from './client.js'
import { isEmbeddingVector } from './fingerprint.js'

type SidecarReply = { model?: unknown; dim?: unknown; vectors?: unknown; truncated?: unknown }

export function createLocalEmbeddingClient(
  settings: EmbeddingSettings,
  fetchImpl: typeof fetch = fetch
): EmbeddingClient {
  const url = `${settings.sidecarUrl.replace(/\/+$/, '')}/embed`
  return {
    async embed(text, role, signal) {
      const timeout = AbortSignal.timeout(settings.timeoutMs)
      const response = await fetchImpl(url, {
        method: 'POST',
        headers: { 'content-type': 'application/json' },
        body: JSON.stringify({ texts: [text], role }),
        signal: AbortSignal.any(signal ? [signal, timeout] : [timeout])
      })
      if (!response.ok) throw new Error(`Embedding sidecar returned HTTP ${response.status}`)
      const reply = (await response.json()) as SidecarReply
      if (reply.model !== settings.model) {
        throw new Error(`Embedding sidecar serves ${String(reply.model)}, but embeddings.model is ${settings.model}`)
      }
      const values = Array.isArray(reply.vectors) ? reply.vectors[0] : undefined
      if (reply.dim !== settings.dim || !isEmbeddingVector(values, settings.dim)) {
        throw new Error('Embedding sidecar returned an invalid embedding')
      }
      if (Array.isArray(reply.truncated) && reply.truncated[0] === true) {
        logger.info({ role, chars: text.length }, 'Embedding input was cut to the 512-token model limit')
      }
      return { values, modelId: settings.model, dim: settings.dim, fingerprint: settings.fingerprint }
    }
  }
}
```

```ts
import type Database from 'better-sqlite3'

export const UNKNOWN_FINGERPRINT = 'unknown'

export type VectorTable = 'memory_episode' | 'media_digest' | 'memory_claim'

const PROVENANCE_COLUMNS = [
  ['embedding_model_id', 'TEXT'],
  ['embedding_dim', 'INTEGER'],
  ['embedding_fingerprint', 'TEXT']
] as const

/**
 * A vector with no recorded provenance predates these columns, so it is marked unknown rather than guessed; its
 * dimension is still knowable from its bytes. Idempotent, and a no-op for a table that does not exist yet.
 */
export function ensureVectorProvenanceColumns(database: Database.Database, table: VectorTable): void {
  const columns = new Set(
    (database.prepare(`PRAGMA table_info('${table}')`).all() as Array<{ name: string }>).map(({ name }) => name)
  )
  if (!columns.has('embedding')) return
  database.transaction(() => {
    for (const [name, type] of PROVENANCE_COLUMNS) {
      if (!columns.has(name)) database.exec(`ALTER TABLE ${table} ADD COLUMN ${name} ${type}`)
    }
    database
      .prepare(
        `UPDATE ${table} SET embedding_dim = length(embedding) / 4, embedding_fingerprint = ?
         WHERE embedding IS NOT NULL AND embedding_fingerprint IS NULL`
      )
      .run(UNKNOWN_FINGERPRINT)
  })()
}
```

```ts
export function encodeFloat32Embedding(vector: EmbeddingVector, label = 'Episode'): Buffer {
  const { values, dim } = vector
  if (
    !Number.isInteger(dim) ||
    dim <= 0 ||
    values.length !== dim ||
    values.some((value) => !Number.isFinite(value) || !Number.isFinite(Math.fround(value)))
  ) {
    throw new Error(`${label} embedding must contain ${dim} finite values`)
  }

  const bytes = Buffer.allocUnsafe(dim * 4)
  values.forEach((value, index) => bytes.writeFloatLE(value, index * 4))
  return bytes
}

export function vectorParams(
  vector: EmbeddingVector | null | undefined,
  label?: string
): [Buffer | null, string | null, number | null, string | null] {
  return vector
    ? [encodeFloat32Embedding(vector, label), vector.modelId, vector.dim, vector.fingerprint]
    : [null, null, null, null]
}

// Every vector stored before provenance was recorded came from the one Gemini 768-dimension recipe (#223), so a
// Gemini space may still read those.
export function isActiveVector(fingerprint: string | null, dim: number | null, byteLength: number): boolean {
  const active = config.embeddings
  if (dim === null || dim !== active.dim || byteLength !== dim * 4) return false
  return fingerprint === active.fingerprint || (fingerprint === UNKNOWN_FINGERPRINT && active.provider === 'gemini')
}

export function decodeFloat32Embedding(row: StoredVector): EpisodeEmbedding | null {
  const bytes = row.embedding
  if (!bytes || !isActiveVector(row.embedding_fingerprint, row.embedding_dim, bytes.byteLength)) return null

  const values = Array.from({ length: bytes.byteLength / 4 }, (_, index) => bytes.readFloatLE(index * 4))
  const squaredNorm = values.reduce((sum, value) => sum + value * value, 0)
  return values.every(Number.isFinite) && squaredNorm > 0 ? values : null
}
```

```ts
// a row mean the provider is down, so the rest waits for the next pass instead of failing one by one.
class BackfillPace {
  private left = config.embeddings.backfillBatchSize
  private failures = 0
  private started = false

  get remaining(): number {
    return this.failures < MAX_CONSECUTIVE_FAILURES && !isShuttingDown() ? this.left : 0
  }

  async next(): Promise<boolean> {
    if (this.remaining === 0) return false
    if (this.started) await delay(config.embeddings.backfillGapMs)
    this.started = true
    this.left -= 1
    return true
  }

  settle(succeeded: boolean): void {
    this.failures = succeeded ? 0 : this.failures + 1
  }
}

let running: Promise<EpisodeMaintenanceReport> | null = null

/**
 * Prunes expired rows, then embeds every retained document with no vector readable in the configured embedding
 * space. One pass runs at a time; the next pass resumes from the provenance each row records.
 */
export function pruneEpisodesAndReembed(nowMs = Date.now()): Promise<EpisodeMaintenanceReport> {
  running ??= runPass(nowMs).finally(() => {
    running = null
  })
  return running
}

async function runPass(nowMs: number): Promise<EpisodeMaintenanceReport> {
  const embedOn = config.memory.privacy !== 'off'
  const pace = new BackfillPace()
  const cutoff = nowMs - config.memory.episodeRetentionDays * 24 * 60 * 60 * 1000
  const deleted = pruneExpiredEpisodes(cutoff)
  let reembedded = 0
  let failed = 0

  for (const guildId of embedOn ? listEpisodeGuildIds() : []) {
    for (const episode of listEpisodesForGuild(guildId)) {
      if (episode.embedding) continue
      if (!(await pace.next())) break
      try {
        const embedding = await embedEpisodeText({ text: episode.summary, role: 'RETRIEVAL_DOCUMENT' })
        if (setEpisodeEmbedding({ guildId, id: episode.id, summary: episode.summary, embedding })) reembedded += 1
        pace.settle(true)
      } catch (error) {
        failed += 1
        pace.settle(false)
        logger.warn({ guildId, episodeId: episode.id, error }, 'Failed to re-embed memory episode')
      }
    }
  }

  const mediaCutoff = nowMs - config.memory.mediaRetentionDays * 24 * 60 * 60 * 1000
  const mediaDeleted = pruneExpiredMediaDigests(mediaCutoff)
  let mediaReembedded = 0
  let mediaFailed = 0

  for (const guildId of embedOn ? listMediaGuildIds() : []) {
    for (const digest of listMediaDigestsForGuild(guildId)) {
      if (digest.embedding) continue
      if (!(await pace.next())) break
      try {
        const embedding = await embedEpisodeText({ text: digest.summary, role: 'RETRIEVAL_DOCUMENT' })
        if (setMediaDigestEmbedding({ guildId, id: digest.id, summary: digest.summary, embedding }))
          mediaReembedded += 1
        pace.settle(true)
      } catch (error) {
        mediaFailed += 1
        pace.settle(false)
        logger.warn({ guildId, mediaDigestId: digest.id, error }, 'Failed to re-embed media digest')
      }
    }
  }

  const facts =
    embedOn && pace.remaining > 0
      ? await embedPendingFacts({ limit: pace.remaining, gapMs: config.embeddings.backfillGapMs })
      : { embedded: 0, failed: 0 }

  return {
    deleted,
    reembedded,
    failed,
    mediaDeleted,
    mediaReembedded,
    mediaFailed,
    factsEmbedded: facts.embedded,
    factsFailed: facts.failed
  }
}
```

Facts need no extra source-text guard. `setClaimEmbedding` writes the vector together with the sentence it was made from (`embedding_text`), so the stored pair always agrees. When the claim changes, the next sweep sees `embeddingText !== sentence` and re-embeds it.

```ts
export interface FeatureExtractor {
  (texts: string[], options: { pooling: 'mean'; normalize: true }): Promise<{ tolist(): unknown }>
  tokenizer: { encode(text: string): number[] }
}

export interface Embedder {
  embed(texts: string[]): Promise<{ vectors: number[][]; tokenCounts: number[] }>
}

export function createEmbedder(extractor: FeatureExtractor): Embedder {
  return {
    async embed(texts) {
      // The pipeline truncates to the model limit by itself; counting first is the only way to report a cut.
      const tokenCounts = texts.map((text) => extractor.tokenizer.encode(text).length)
      const output = await extractor(texts, { pooling: 'mean', normalize: true })
      return { vectors: output.tolist() as number[][], tokenCounts }
    }
  }
}
```

`sidecar/embeddings/src/handler.ts`:

```ts
import type { IncomingMessage, ServerResponse } from 'node:http'
import type { Embedder } from './embedder.js'

export const MAX_TOKENS = 512
export const MAX_TEXTS = 16
export const MAX_BODY_BYTES = 1_048_576

const PREFIXES = { query: 'query: ', document: 'passage: ' } as const

type Role = keyof typeof PREFIXES
type Reply = { status: number; body: unknown }

export type Log = (level: 'info' | 'error', message: string, fields?: Record<string, unknown>) => void

export interface HandlerOptions {
  embedder: Embedder
  model: string
  dim: number
  log: Log
}

function parseEmbedRequest(body: unknown): { texts: string[]; role: Role } | string {
  if (typeof body !== 'object' || body === null) return 'body must be a JSON object'
  const { texts, role } = body as Record<string, unknown>
  if (role !== 'query' && role !== 'document') return 'role must be query or document'
  if (
    !Array.isArray(texts) ||
    texts.length === 0 ||
    texts.length > MAX_TEXTS ||
    !texts.every((text) => typeof text === 'string')
  ) {
    return `texts must be 1 to ${MAX_TEXTS} strings`
  }
  return { texts, role }
}

async function readBody(request: IncomingMessage): Promise<string | null> {
  const chunks: Buffer[] = []
  let size = 0
  for await (const chunk of request as AsyncIterable<Buffer>) {
    size += chunk.length
    // Keep draining past the cap, so the client gets a 413 instead of a reset connection.
    if (size <= MAX_BODY_BYTES) chunks.push(chunk)
  }
  return size > MAX_BODY_BYTES ? null : Buffer.concat(chunks).toString('utf8')
}

export function createHandler(
  options: HandlerOptions
): (request: IncomingMessage, response: ServerResponse) => Promise<void> {
  const { embedder, model, dim, log } = options
  // One inference thread: each request waits for the one before it.
  let previous: Promise<unknown> = Promise.resolve()

  async function embed(texts: string[], role: Role): Promise<Reply> {
    const run = previous.then(() => embedder.embed(texts.map((text) => PREFIXES[role] + text)))
    previous = run.catch(() => undefined)
    const { vectors, tokenCounts } = await run
    if (vectors.length !== texts.length || vectors.some((vector) => vector.length !== dim)) {
      throw new Error('The model returned an unexpected shape')
    }
    const truncated = tokenCounts.map((count) => count > MAX_TOKENS)
    tokenCounts.forEach((tokens, index) => {
      if (truncated[index]) log('info', 'Input truncated to the model limit', { role, tokens, limit: MAX_TOKENS })
    })
    return { status: 200, body: { model, dim, vectors, truncated } }
  }

  async function route(request: IncomingMessage): Promise<Reply> {
    const path = new URL(request.url ?? '/', 'http://sidecar').pathname
    if (request.method === 'GET' && path === '/health') return { status: 200, body: { ok: true, model, dim } }
    if (request.method !== 'POST' || path !== '/embed') return { status: 404, body: { error: 'not found' } }
    const raw = await readBody(request)
    if (raw === null) return { status: 413, body: { error: `body is over ${MAX_BODY_BYTES} bytes` } }
    let parsed: unknown
    try {
      parsed = JSON.parse(raw)
    } catch {
      return { status: 400, body: { error: 'body must be JSON' } }
    }
    const input = parseEmbedRequest(parsed)
    if (typeof input === 'string') return { status: 400, body: { error: input } }
    try {
      return await embed(input.texts, input.role)
    } catch (error) {
      log('error', 'Embedding failed', { error: error instanceof Error ? error.message : String(error) })
      return { status: 500, body: { error: 'embedding failed' } }
    }
  }

  return async (request, response) => {
    const reply = await route(request)
    response.writeHead(reply.status, { 'content-type': 'application/json' })
    response.end(JSON.stringify(reply.body))
  }
}
```

```ts
import { strict as assert } from 'node:assert'
import { readFile, writeFile } from 'node:fs/promises'

type EmbedReply = { model: string; dim: number; vectors: number[][]; truncated: boolean[] }

const url = process.argv.find((arg) => arg.startsWith('http')) ?? 'http://127.0.0.1:8080'
const record = process.argv.includes('--record')
const goldenPath = new URL('../golden.json', import.meta.url)

async function embed(texts: string[], role: 'document' | 'query'): Promise<EmbedReply> {
  const response = await fetch(`${url}/embed`, {
    method: 'POST',
    headers: { 'content-type': 'application/json' },
    body: JSON.stringify({ texts, role })
  })
  assert.equal(response.status, 200, `POST /embed returned ${response.status}`)
  return (await response.json()) as EmbedReply
}

const dot = (left: number[], right: number[]) =>
  left.reduce((sum, value, index) => sum + value * (right[index] ?? 0), 0)

assert.equal((await fetch(`${url}/health`)).status, 200, '/health is not ready')
const documents = await embed(
  [
    'The group planned a picnic by the river on Saturday.',
    'Someone shared a ramen recipe with extra garlic.',
    'word '.repeat(700)
  ],
  'document'
)
const query = await embed(['Where are we going for the picnic?'], 'query')
const [picnic, ramen] = documents.vectors
const [question] = query.vectors
assert.ok(picnic && ramen && question, 'missing vectors')
assert.equal(documents.dim, 384)
for (const vector of [...documents.vectors, ...query.vectors]) {
  assert.equal(vector.length, 384)
  assert.ok(Math.abs(Math.hypot(...vector) - 1) < 1e-3, 'vector is not unit length')
}
assert.ok(dot(question, picnic) > dot(question, ramen), 'the related passage does not outrank the unrelated one')
assert.deepEqual(documents.truncated, [false, false, true])

const golden = { model: documents.model, picnic: picnic.slice(0, 8), question: question.slice(0, 8) }
if (record) {
  await writeFile(goldenPath, `${JSON.stringify(golden, null, 2)}\n`)
  console.log(`Recorded ${goldenPath.pathname}`)
} else {
  const saved = JSON.parse(await readFile(goldenPath, 'utf8')) as typeof golden
  assert.equal(saved.model, golden.model)
  for (const key of ['picnic', 'question'] as const) {
    saved[key].forEach((value, index) => {
      assert.ok(
        Math.abs(value - (golden[key][index] ?? Number.NaN)) < 1e-4,
        `${key}[${index}] drifted from golden.json`
      )
    })
  }
}
console.log('Embedding sidecar smoke test passed', { model: documents.model, dim: documents.dim })
```

`sidecar/embeddings/README.md`:

````markdown
# Embedding Sidecar

A small HTTP service that turns memory text into vectors for the bot when `embeddings.provider` is `local`. It runs
[Transformers.js](https://github.com/huggingface/transformers.js) 4.3.0 on `onnxruntime-node` 1.30.0 with
`Xenova/multilingual-e5-small` (q8, 384 dimensions), baked into the image at revision `761b726d`. It targets a
Raspberry Pi 5 (arm64) as well as amd64. The image is Debian-based because the native ONNX runtime needs glibc.

## API

### `GET /health`

Returns `200 {"ok": true, "model": "...", "dim": 384}`. The server listens only after the model has loaded and answered
one warm-up request, so the endpoint is unreachable before that.

### `POST /embed`

- Body: `{"texts": string[], "role": "document" | "query"}`, with 1 to 16 texts and at most 1 MiB. Other bodies get `400`; larger ones get `413`.
- Each text gets the E5 prefix for its role (`passage: ` or `query: `), then mean pooling and L2 normalisation.
- Texts past 512 tokens are truncated. `truncated` reports which ones, and the sidecar logs the token count, never the text.
- Requests run one at a time on one inference thread.

Response (`200`):

```json
{ "model": "Xenova/multilingual-e5-small@761b726d-q8", "dim": 384, "vectors": [[0.01]], "truncated": [false] }
```

`model` names the repository, the first eight characters of the revision and the quantisation. The bot stores it with
every vector and compares only vectors with the same `model`, so a build with another revision starts a new embedding
space. Errors return `{"error": "..."}`.

## Configuration

- `EMBEDDINGS_PORT`: listen port (default `8080`).
- `EMBEDDINGS_MODEL`, `EMBEDDINGS_REVISION`, `EMBEDDINGS_MODEL_DIR`: set by the image. Change them only together with the `Dockerfile` build arguments and `model.sha256`.

Remote downloads are disabled at runtime. The build fetches the model files once from the pinned revision and checks
them against `model.sha256`; a mismatch fails the build.

## Build and Run

```bash
docker build -t rokabot-embeddings sidecar/embeddings
docker run --rm -p 8080:8080 rokabot-embeddings
curl -s -X POST -H 'content-type: application/json' -d '{"texts":["We planned a picnic."],"role":"document"}' http://localhost:8080/embed
```

In the stack it runs as the `embeddings` service under the compose profile `local-embeddings`. The bot reaches it at
`http://embeddings:8080`.

## Tests

`npm test` in the repository root runs `src/__tests__/` with a stubbed pipeline. It downloads no model.

## Smoke Test

With the container running, `npx tsx sidecar/embeddings/scripts/smoke.ts http://localhost:8080` checks the real model:
dimensions, unit norms, a related passage outranking an unrelated one, truncation past 512 tokens, and the first
values against `golden.json`. `--record` rewrites `golden.json`. The smoke test is not part of `npm test`.

## Model and Licences

- `intfloat/multilingual-e5-small` (ONNX export `Xenova/multilingual-e5-small`): MIT.
- Transformers.js: Apache-2.0. ONNX Runtime: MIT.
````

## Risks and Open Questions

- **Pi memory.** The 300–650 MiB footprint is an estimate. The release gate (peak RSS under 800 MiB while speech recognition and an attachment run) is an owner follow-up on the Pi.
- **Thresholds.** The local floors (0.86 and 0.84) are placeholders. Do not switch the Pi to `local` before calibration (Phase 3). OpenAI has no entry, so it falls back to the Gemini floors with a startup warning.
- **Query priority and media pausing.** The spec says backfill pauses during media work. No in-flight media signal exists, so this plan relies on 1 doc/s pacing and the sidecar's first-in, first-out single-request queue: a turn's query waits at most one document's inference. A real pause hook is open.
- **Model files.** If Transformers.js 4.3.0 needs a file outside the five pinned ones, Task 9 Step 7 catches it at the first build.
- **Graph refresh.** `graphify update .` is left until after the #296 chain merges, to avoid `graph.json` conflicts between plans.
- **Conflicts.** `src/config.ts`, `config.yml`, `src/__tests__/config.test.ts`, `tests/vitest.setup.ts` and `src/storage/database.ts` are shared with 1A, 1B and 2. Resolve them by merging `main` into the branch, never by force-pushing.

## Contract Issues

1. **Unknown provenance versus the legacy guarantee.** The spec says legacy vectors stay "unknown provenance" until re-embedded and that recall compares only matching fingerprints. Read literally, that blanks Gemini semantic recall on the Pi until a full re-embed, which breaks "legacy config unchanged". This plan lets a Gemini 768-dimension space read `unknown` vectors, and backfills them only when the active space is not Gemini.
2. **`config.embeddings` shape.** The contract lists `{ provider, model, timeoutMs, sidecarUrl, apiKey? }`. This plan adds `dim`, `fingerprint`, `backfillBatchSize` and `backfillGapMs` (a superset). `apiKey` is always present as `string | undefined`.
3. **Sidecar `model`.** The contract types it only as `string`. This plan fixes it as `<repo>@<rev8>-<dtype>`, so the fingerprint covers revision and quantisation. For `local`, `embeddings.model` is that full id.
4. **Usage and budgets.** "Every adapter calls `recordUsage`" and "paid backfill draws on the monthly cap" have no embedding counterpart here, because embedding prices have no home in `ModelProfile` and 1D's reservations would put legacy embedding calls behind replies. This is deferred to Phase 3; the `embedding` workload stays unused.
5. **Legacy trigger.** The spec ties the legacy setup to "no `llm:` block"; the contract ties it to "no `embeddings:` block". This plan follows the contract, so an Anthropic-only setup must set `embeddings.provider: local` (or `EMBEDDINGS_PROVIDER=local`), or startup asks for `GEMINI_API_KEY`. The shipped `config.yml` pins `gemini` so the Pi stays put.
6. **OpenAI scope.** The spec puts the OpenAI embedding profile in Phase 3, but this plan ships `openai.ts` as asked, uncalibrated. `OPENAI_API_KEY` in `.env.example` stays with Plan 2.

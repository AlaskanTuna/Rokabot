# 1D Budgets Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace plan 1A's always-grant `reserveCall` stub with real per-call budgets: per-model request and token limits, ModelScope's one-at-a-time sending and shared daily Magicube estimate, and a persisted monthly spend cap per provider. The legacy config keeps today's limits and today's Discord decline behaviour.

**Architecture:** `src/agent/llm/budget.ts` is the one gate in front of every provider call (`startCall` waits for a provider slot, then calls the synchronous `reserveCall`). Request windows stay in `RateLimiter` and token minutes in a `TokenBucket`, now one of each per provider and model. The main model's limiter is still the one the Discord guard reserves whole turns on (#167), so reply calls on the main model are not counted twice, and background calls must leave one whole reply turn free. Spend comes from `recordUsage` events priced by the model profile and lands in a new `llm_spend` table. A spent month makes `startCall` throw `ProviderError` kind `billing_exhausted` until the UTC month turns.

**Tech Stack:** TypeScript (Node 24, ESM, `module: Node16`), `@google/adk` 2.2.1 `BaseLlm` adapters, `better-sqlite3`, vitest 3 with fake timers, Biome 1.9 + Prettier.

## Design Decisions

Read these before Task 1. They explain choices the tasks rely on.

1. **The turn reservation stays.** The Discord handlers keep `canAdmitCalls(maxLlmCalls)` and `reserveCalls(maxLlmCalls)` on the main model's shared limiter, so every decline and busy message is unchanged. Removing it would re-open #167 (admitted turns refused mid-tool-loop) and change what the user sees. Per-call reservations sit underneath it.
2. **Reply and watcher calls on the main model are "covered by the turn".** They skip the request window (the turn already holds those slots) but still pay tokens, spend and the monthly cap. Every other call (background workloads, the fallback model, a watcher on another model) takes its own request slot.
3. **The day is counted in requests.** Today `rateLimiter.ts:128` charges one daily unit per turn. Now the reservation takes one unit at admission (so the last unit of the day still admits a turn, exactly as today) and `release(used)` adds the calls made beyond the first. This closes the gap `docs/trd.md` "RPM-Budget Accounting" names.
4. **Replies outrank background work by headroom, not preemption.** A background call is refused unless, after it, a whole reply turn still fits: `maxLlmCalls` requests, `maxLlmCalls` daily units, `maxLlmCalls` Magicubes, and `gemini.maxAttachmentTokens` tokens. Text replies are never refused on tokens (today's rule). In ModelScope's single-slot queue, waiting replies go ahead of waiting background calls.
5. **Tokens are charged per call.** Each call charges its estimate when it is reserved and settles to the provider's reported prompt tokens on `release(usage)`. `roka.ts` stops charging the turn's `tokensInEst`, which would now count every call twice.
6. **ModelScope concurrency waits, it does not refuse.** A refusal would turn into `quota_exhausted` and open a sticky window on a perfectly healthy provider. `startCall` therefore waits for the slot, bounded by the call's abort signal. This is why adapters call the async `startCall`, not `reserveCall` directly.
7. **Magicubes:** one shared daily counter for every ModelScope model, the qwen watcher included, at 1 Magicube per call, reset at UTC midnight, in memory. A spent estimate refuses as `'rpd'`.
8. **Monthly spend** is summed from `recordUsage` events (so retries and losing hedge calls count, since each is its own call) and priced by `estimateCostUsd` in `usage.ts`. It is persisted per UTC month and provider in `llm_spend`, so the cap survives restarts. A provider's own billing error (`markBillingExhausted`) is held in memory only, so a restart after topping up is the owner's way to re-enable the route early.
9. **Embeddings are not metered here.** Paid embedding accounting is Phase 3 in the spec.

Deliberate differences on the legacy config (keep them in the PR description):

- `rateLimit.rpd` now counts requests, so a tool-heavy day reaches 500 sooner than 500 turns.
- The minute's tokens include every tool-loop, retry and watcher call, so attachment turns can be declined slightly sooner under load.
- The ModelScope fallback and the qwen watcher (`MEDIA_WATCHER=qwen` on the Pi) send one request at a time and stop after an estimated 250 calls a day.

```ts
function routeLimitBounds(
  route: ResolvedModel | null,
  isMain: boolean
): Array<{ path: string; value: number; min: number }> {
  if (!route?.limits || route.key.startsWith('legacy-')) return []
  const path = `llm.models.${route.key}.limits`

    ...(rpm === undefined ? [] : [{ path: `${path}.rpm`, value: rpm, min: isMain ? config.gemini.maxLlmCalls : 1 }]),
    ...(rpd === undefined ? [] : [{ path: `${path}.rpd`, value: rpd, min: 1 }]),
    ...(tpm === undefined
      ? []
      : [{ path: `${path}.tpm`, value: tpm, min: isMain ? config.gemini.maxAttachmentTokens : 1 }])
  ]
}
```

```ts
import { config } from '../config.js'
import { logger } from '../utils/logger.js'

/**
 * Tokens spent per rolling minute, which is the quota the request limiter does not measure.
 *
 * `rateLimit.rpm` bounds how many turns happen, and that bounded spend adequately while every turn cost about the
 * same — a text turn is ~5,600 tokens, so 15 of them is 34% of the measured 250,000 TPM. Attachments end that: one
 * turn may now carry `gemini.maxAttachmentTokens`, and 15 of those is over three times the minute's budget. Neither
 * existing guard catches it. `byteBudget` meters bytes, and the whole finding of #136 is that bytes do not bound
 * tokens — an 89-page PDF measures 49,841 tokens in 35 KB, passing the per-turn ceiling and reserving 0.1% of the
 * byte budget while fifteen of them would spend 333% of the minute.
 *
 * One bucket per model rather than per channel: TPM is the provider's quota on the model, so overspending lands on
 * every other channel rather than on the sender. It was Gemini-only until #296.
 */
export class TokenBucket {
  private spent = 0
  private lastDrain = Date.now()

  constructor(private readonly perMinute: number) {}

  /** Tokens drain continuously rather than resetting on a boundary, mirroring the RPM bucket's refill. */
  private drain(): void {
    const now = Date.now()
    const elapsed = now - this.lastDrain
    if (elapsed <= 0) return

    this.spent = Math.max(0, this.spent - (elapsed * this.perMinute) / 60_000)
    this.lastDrain = now
  }

  /** Tokens still available in the rolling minute. */
  remaining(): number {
    this.drain()
    return Math.max(0, this.perMinute - this.spent)
  }

  /**
   * Record tokens sent. Always charged and never refused: a call that has reached this point has been admitted, and
   * declining to account for it would leave the budget describing something other than what was spent.
   */
  charge(tokens: number): void {
    this.drain()
    this.spent += Math.max(0, tokens)
  }

  /** Hand back an estimate once the provider has said what the call really cost. */
  refund(tokens: number): void {
    this.drain()
    this.spent = Math.max(0, this.spent - Math.max(0, tokens))
  }
}

const buckets = new Map<string, TokenBucket>()

/** The model's bucket, made on first use, or null when its entry sets no `tpm` and nothing is metered. */
export function tokenBucketFor(model: {
  provider: string
  model: string
  limits?: { tpm?: number }
}): TokenBucket | null {
  const perMinute = model.limits?.tpm
  if (perMinute === undefined) return null
  const key = `${model.provider}/${model.model}`
  let bucket = buckets.get(key)
  if (!bucket) {
    bucket = new TokenBucket(perMinute)
    buckets.set(key, bucket)
  }
  return bucket
}

/** Tokens still available in the main model's rolling minute; unlimited when its entry sets no `tpm`. */
export function remainingTokensThisMinute(): number {
  return tokenBucketFor(config.llm.main)?.remaining() ?? Number.POSITIVE_INFINITY
}

/**
 * Charge the main model's minute directly. Provider calls are charged by `src/agent/llm/budget.ts` where they are
 * sent; this stays as the seam the budget simulations spend through.
 */
export function chargeTokens(tokens: number): void {
  tokenBucketFor(config.llm.main)?.charge(tokens)
}

/**
 * Whether a turn carrying attachments should be admitted, judged against the most one could cost rather than
 * against what this one will.
 *
 * The exact cost is only knowable after the file has been downloaded and measured, which is far too late to
 * decline politely — so this asks the answerable question instead: is there room for the worst turn the
 * per-turn ceiling admits? Text turns are never gated, because `rpm` already bounds them to about a third of
 * the budget; the config bounds pin that relationship so it cannot quietly stop being true.
 */
export function canAffordAttachments(): boolean {
  const remaining = remainingTokensThisMinute()
  const needed = config.gemini.maxAttachmentTokens

  if (remaining < needed) {
    logger.info(
      { remaining: Math.round(remaining), needed },
      'Not enough of this minute token budget for an attachment turn'
    )
    return false
  }
  return true
}

/** Test seam: buckets are module state, and a leaked balance would make later tests refuse for no reason. */
export function __resetTokenBudgetForTest(): void {
  buckets.clear()
}
```

```ts
/** The UTC calendar month a monthly cap resets on, e.g. `2026-10`. */
export function monthKey(nowMs: number = Date.now()): string {

}

export function readSpend(month: string, provider: string): number {
  const row = getDb().prepare('SELECT usd FROM llm_spend WHERE month = ? AND provider = ?').get(month, provider) as
    | { usd: number }

}

/** Never throws: it runs inside a provider call, and losing one estimate must not fail the reply that cost it. */

          'ON CONFLICT (month, provider) DO UPDATE SET usd = usd + excluded.usd'
      )
      .run(month, provider, usd)
  } catch (error) {
    logger.warn({ err: error, month, provider }, 'Failed to record LLM spend')
  }
```

```ts
// Writing a cache bills above plain input: 1.25x on Anthropic's 5-minute cache and on OpenAI's (budget-model survey).
// The profile carries no write price of its own, so it is derived here.
const CACHE_WRITE_PRICE_MULTIPLIER = 1.25

/**
 * Estimated USD for one call, from its profile's prices per million tokens. The usage buckets are disjoint:
 * `inputTokens` excludes cache reads and writes, and `outputTokens` excludes `reasoningTokens`, which bill as output.
 * The provider's bill stays the source of truth.
 */
export function estimateCostUsd(usage: CallUsage): number {
  const price = profileFor(usage.provider, usage.model)?.price
  if (!price) return 0
  const cacheRead = (usage.cacheReadTokens ?? 0) * (price.cachedInput ?? price.input)
  const cacheWrite = (usage.cacheWriteTokens ?? 0) * price.input * CACHE_WRITE_PRICE_MULTIPLIER
  const output = (usage.outputTokens + (usage.reasoningTokens ?? 0)) * price.output
  return (usage.inputTokens * price.input + cacheRead + cacheWrite + output) / 1_000_000
}
```

```ts
/**
 * Per-call budgets in front of every provider call: request and token rates per model, ModelScope's one-at-a-time
 * sending and shared daily Magicubes, and each provider's estimated monthly spend.
 *
 * A reply turn already reserves its whole ceiling of requests on the main model's shared limiter, in the Discord
 * layer (#167), so reply and watcher calls on the main model are not counted again here. Every other call takes its
 * own slot. A background call only gets capacity that still leaves one whole reply turn behind it: that is how
 * replies outrank background work without preempting anything already in flight.
 */

import { config } from '../../config.js'
import { logger } from '../../utils/logger.js'
import { __resetRateLimitersForTest, rateLimiterFor } from '../../utils/rateLimiter.js'
import type { ProviderId } from './profiles.js'
import { ProviderError } from './providerError.js'
import type { CallUsage, Workload } from './usage.js'

export type BudgetDenial = 'rpm' | 'rpd' | 'tpm' | 'monthly'

export interface CallInput {
  provider: ProviderId
  model: string
  workload: Workload
  estTokens: number
}

export interface BudgetReservation {
  /** Pass the provider's reported usage so the minute's tokens settle at the real figure rather than the estimate. */
  release(usage?: CallUsage): void
}

const REPLY_SIDE: ReadonlySet<Workload> = new Set<Workload>(['reply', 'watcher'])

const MINUTE_MS = 60_000

function routeLimits(provider: ProviderId, model: string) {
  const route = [config.llm.main, config.llm.fallback].find(
    (entry) => entry?.provider === provider && entry.model === model
  )
  return route?.limits
}

/** Reserve one provider call, or name the budget that refused it. Adapters call `startCall`, which wraps this. */
export function reserveCall(input: CallInput): BudgetReservation | { denied: BudgetDenial } {
  const { provider, model, workload } = input
  const replySide = REPLY_SIDE.has(workload)
  const main = config.llm.main
  // The Discord layer reserved this turn's whole ceiling on the main model's limiter (#167); counting each of its
  // calls here as well would charge every reply twice.
  const coveredByTurn = replySide && main.provider === provider && main.model === model
  // A background call leaves one whole reply turn behind it, so the next reply is admitted rather than declined.
  const headroom = replySide ? 0 : config.gemini.maxLlmCalls
  const limits = routeLimits(provider, model)
  const limiter = rateLimiterFor({ provider, model, limits })

  let denied: BudgetDenial | null = null
  if (!coveredByTurn && limiter.remainingRpd < 1 + headroom) denied = 'rpd'
  else if (!coveredByTurn && limiter.remainingRpm < 1 + headroom) denied = 'rpm'
  if (denied) {
    logger.info({ provider, model, workload, denied }, 'Budget declined a model call')
    return { denied }
  }

  if (!coveredByTurn) limiter.tryConsume()
  return { release: () => {} }
}

/** The router's view of a refusal: a spent month disables the route until it turns; anything else is a quota wait. */
function budgetDenialError(provider: ProviderId, denied: BudgetDenial): ProviderError {
  const now = new Date()
  if (denied === 'monthly') {
    return new ProviderError({
      provider,
      kind: 'billing_exhausted',
      message: `${provider} has reached its monthly budget`,
      retryAfterMs: Date.UTC(now.getUTCFullYear(), now.getUTCMonth() + 1, 1) - now.getTime()
    })
  }
  return new ProviderError({
    provider,
    kind: 'quota_exhausted',
    message: `${provider} is over its local ${denied} budget`,
    retryAfterMs:
      denied === 'rpd'
        ? Date.UTC(now.getUTCFullYear(), now.getUTCMonth(), now.getUTCDate() + 1) - now.getTime()
        : MINUTE_MS
  })
}

/** Reserve the call or throw the ProviderError the router acts on. Every adapter calls this before it sends. */
export async function startCall(input: CallInput & { signal?: AbortSignal }): Promise<BudgetReservation> {
  const reservation = reserveCall(input)
  if ('denied' in reservation) throw budgetDenialError(input.provider, reservation.denied)
  return reservation
}

/** Test seam: every budget is module state, and one test's spent minute would refuse the next test's calls. */
export function __resetBudgetsForTest(): void {
  __resetRateLimitersForTest()
}
```

```ts
// Per-model Magicube tiers are shown only to a logged-in account, so every call is counted at the standard tier.
const MAGICUBES_PER_CALL = 1

// ModelScope guarantees one concurrent request per account and promises nothing past it.
const CONCURRENCY: Partial<Record<ProviderId, number>> = { modelscope: 1 }

let magicubes = { day: '', used: 0 }
const inFlight = new Map<ProviderId, number>()
const waiting = new Map<ProviderId, Array<{ reply: boolean; grant: () => void }>>()

/** Magicubes left in the shared ModelScope estimate; it resets with the UTC day, like the request limiter's. */
function magicubesLeft(): number {
  const day = new Date().toISOString().slice(0, 10)
  if (magicubes.day !== day) magicubes = { day, used: 0 }
  return config.llm.modelscopeDailyMagicubes - magicubes.used
}

/**
 * Waits for one of the provider's in-flight slots. A refusal here would surface as quota exhaustion on a healthy
 * provider and open a sticky window, so the call waits instead, for as long as its own signal allows. Replies wait
 * behind replies already waiting and ahead of every background call.
 */
function acquireSlot(provider: ProviderId, reply: boolean, signal?: AbortSignal): Promise<() => void> {
  const limit = CONCURRENCY[provider]
  if (limit === undefined) return Promise.resolve(() => {})
  signal?.throwIfAborted()

  let held = true
  const leave = () => {
    if (!held) return
    held = false
    inFlight.set(provider, (inFlight.get(provider) ?? 1) - 1)
    waiting.get(provider)?.shift()?.grant()
  }
  const queue = waiting.get(provider) ?? []
  waiting.set(provider, queue)
  if ((inFlight.get(provider) ?? 0) < limit && queue.length === 0) {
    inFlight.set(provider, (inFlight.get(provider) ?? 0) + 1)
    return Promise.resolve(leave)
  }

  return new Promise((resolve, reject) => {
    const waiter = { reply, grant: () => {} }
    const onAbort = () => {
      queue.splice(queue.indexOf(waiter), 1)
      reject(signal?.reason)
    }
    waiter.grant = () => {
      signal?.removeEventListener('abort', onAbort)
      inFlight.set(provider, (inFlight.get(provider) ?? 0) + 1)
      resolve(leave)
    }
    signal?.addEventListener('abort', onAbort, { once: true })
    const firstBackground = reply ? queue.findIndex((entry) => !entry.reply) : -1
    if (firstBackground === -1) queue.push(waiter)
    else queue.splice(firstBackground, 0, waiter)
  })
}
```

```ts
/** Whether `provider` may take no more calls this month: its local cap is spent, or it reported its credit gone. */
export function isMonthlyExhausted(provider: ProviderId): boolean {
  const month = monthKey()
  if (billingExhaustedIn.get(provider) === month) return true
  const cap = config.llm.monthlyBudgetUsd[provider]

export function markBillingExhausted(provider: ProviderId): void {

function recordSpend(usage: CallUsage): void {
  const usd = estimateCostUsd(usage)
  if (usd <= 0) return

  if (cap !== undefined && before < cap && before + usd >= cap) {

  }
}
```

## Risks and Open Questions

- **Legacy Deltas:** the three deliberate differences under "Design Decisions" change behaviour on the Pi. They are small, and each closes a known gap, but the owner should accept them in the PR.
- **Magicube Estimate:** 1 per call is a guess (tiers are visible only when logged in), the counter is in memory and resets at UTC midnight and on restart, and the real grant's reset time is unknown. If the real grant is lower, ModelScope's own 429 still guards.
- **Spend Accuracy:** depends on 1A's usage normalisation and on losing hedge calls being recorded (Task 0 Step 4, Task 9 Step 6). An aborted call is charged at its input estimate only.
- **Restart Re-Enables Billing Blocks:** deliberate (it is the owner's recovery lever), but a crash loop would re-try the provider once per restart.
- **Watcher Halves:** `turnMedia.ts:324` still reads the main model's minute. With a non-Gemini main that sets `tpm`, the Gemini watcher's halves check reads the wrong bucket (conservatively). Left as is.

## Contract Issues

1. **`reserveCall` is synchronous, so it cannot wait for ModelScope's slot or throw for the router.** This plan adds `startCall(input & { signal })` (async: waits, reserves, throws `ProviderError`) and switches every adapter to it. The contract should name `startCall` as the adapter entry point and keep `reserveCall` as its synchronous core.
2. **The contract does not say how an adapter learns a call's `workload`.** Priority and the turn-coverage rule depend on it. Proposal: `RoutedLlm` passes `'reply'`, and `generateObject` (1B) passes its `workload` through an AsyncLocalStorage in `usage.ts` that every adapter reads.
3. **`CallUsage` has no token convention.** This plan fixes it as disjoint buckets (`inputTokens` excludes cache reads and writes; `outputTokens` excludes `reasoningTokens`) and asks adapters to normalise. Please add that sentence to the contract.
4. **`ModelProfile.price` has no cache-write price.** This plan derives it as 1.25x input. Proposal: add `cacheWrite?: number`.
5. **`config.llm` gains `modelscopeDailyMagicubes: number`** (additive). Please add it to the contract's `config.llm` shape.
6. **Provider billing errors need a shared hook.** An adapter that classifies the provider's own billing error must call `markBillingExhausted(provider)`; plan 2 (OpenAI) needs the same rule. Please add it to "Adapter Rules".
7. **`release(usage?)` semantics are unstated.** This plan uses them to settle the minute's tokens at the reported figure. Please say "pass the same `CallUsage` given to `recordUsage`, or nothing when the call failed before usage came back".
8. **`FailureKind` has no minute-shaped quota kind.** Local `rpm`/`tpm` refusals map to `quota_exhausted` with `retryAfterMs` of 60 s, a spent day to `quota_exhausted` until UTC midnight. 1A's sticky handling should honour `retryAfterMs` rather than assume a day.
9. **`src/agent/llm/budget.ts` is missing from the ownership table** (it appears only under "Budgets (1D)"). Please list it under 1D.
